Privacy Policy

Project 25 · last updated 31 August 2026

Project 25 is a personal life-dashboard application built and operated by one individual for their own private use. It is not a commercial product, it has no user accounts, and it is not offered as a service to the public.

Google account data

The application can display a read-only agenda from a single Google Calendar account — the account belonging to the person who set it up. It requests one Google API scope:

  • https://www.googleapis.com/auth/calendar.readonly

This scope grants read access only. The application cannot create, modify or delete calendar events, and no code path in it attempts to.

How calendar data is handled

  • Calendar events are fetched on demand and held in browser memory only. They are never written to a database, never cached to disk, and are discarded when the page is closed.
  • Each event is trimmed on the server before it reaches the browser, to its title, location, start and end times, and a link back to Google Calendar. Attendee email addresses, event descriptions and conference join links are discarded and never transmitted.
  • The only calendar-related information the application stores is a list of which calendars to display, plus display preferences such as how many days ahead to look.
  • Google account data is never sold, never shared with third parties, and is never used for advertising, profiling or analytics.
  • Project 25's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other data

Personal notes, goals, habits, finance records and similar content entered into the application are stored in a private database belonging to the operator. None of it is derived from Google account data, and none of it is shared with anyone.

Retention and revocation

The application holds a Google authorization token so it can read the calendar without prompting for sign-in each time. That authorization can be withdrawn at any moment from Google Account › Third-party apps & services. Revoking it immediately and permanently ends the application's access. Since no calendar events are stored, revoking leaves nothing behind to delete.
